# Complete Function Hall Booking Application

## Included files
- frontend/index.html
- frontend/package.json
- frontend/src/main.jsx
- frontend/src/style.css
- backend/package.json
- backend/server.js

## Features
- Multiple function halls
- Marriage, birthday, reception, engagement and corporate events
- Guest count
- Veg and Non-Veg food
- Automatic price calculation
- UPI/Card/Net Banking/Cash payment selection
- Node.js + Express REST API
- Booking ID
- Mobile responsive frontend

## Run backend
Open terminal:
cd backend
npm install
npm start

## Run frontend
Open another terminal:
cd frontend
npm install
npm run dev

Open the Vite URL shown in the terminal.

Payment is a demo selection only. For real payments, integrate a payment gateway and verify payments on the server.
